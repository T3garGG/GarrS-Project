# Tool Categories

## Downloaders

Tools that fetch public media through configured provider APIs.

- TikTok Downloader
- Instagram Downloader
- YouTube Downloader

## Productivity

Browser-first utilities with no upload or persistence by default.

- QR Generator
- JSON Formatter
- Text Toolkit
- Password Generator
- Date Toolkit

## Media Tools

Local browser processing preferred.

- Image Compressor

## Communication

Tools that require account access and server-side data.

- Public Chat
- WhatsApp Bot
- Telegram Bot

## Admin

Restricted tools for account and application management.

- Admin Panel
- Profile Settings

## Navigation rules

- Dashboard shows categories, not every tool in one flat grid.
- `/dashboard/tools` is the productivity tool hub.
- Downloaders remain under their existing routes.
- Admin and bot routes stay separated from public productivity tools.
- Every catalog item has a stable key for permission and analytics.
