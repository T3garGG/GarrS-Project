# Audit Fitur — Downloader Dashboard

Tanggal: 2026-11-05

## Stabil secara kode

- Next.js 14 App Router dan TypeScript terpasang.
- Prisma client dan PostgreSQL datasource terkonfigurasi.
- NextAuth Credentials Provider dengan JWT session tersedia.
- Middleware melindungi `/dashboard` dan `/admin`.
- Role `OWNER`, `ADMIN`, `MEMBER` dan permission feature tersedia.
- Admin user management, splash settings, bot connections, chat, dan profile route tersedia.
- Git remote aktif: `https://github.com/T3garGG/GarrS-Project.git`.

## Parsial atau belum siap publik

- Endpoint downloader TikTok, Instagram, dan YouTube hanya meneruskan URL ke third-party API.
- Tidak ada rate limit pada login, downloader, chat, atau webhook.
- Tidak ada download history atau queue.
- Tidak ada retry terkontrol atau status job.
- Validasi request downloader masih manual dan hanya memeriksa string kosong.
- Guest mode belum tersedia.
- Monitoring, health check, analytics, dan error tracking belum tersedia.
- Terms of Service dan Privacy Policy belum tersedia.
- Bot runtime eksternal belum termasuk project ini.

## Verifikasi build

Build awal gagal karena `NODE_ENV=development` diwariskan ke proses `next build`, memicu error prerender:

- `TypeError: Cannot read properties of null (reading 'useContext')`
- `Error: <Html> should not be imported outside of pages/_document.`

Perbaikan:

- Upgrade Next.js ke `14.2.30`.
- Tambah `cross-env`.
- Paksa `NODE_ENV=production` untuk Prisma generate dan Next build.
- Hapus `.next` lalu build ulang.

Hasil: `npm run build` berhasil, 26/26 halaman tergenerate.

Catatan: npm melaporkan 8 vulnerabilities dan Next.js `14.2.30` punya advisory security. Upgrade major perlu diuji terpisah.

## Prioritas perbaikan

1. Audit auth, session, permission, dan account recovery.
2. Tambahkan rate limiting sebelum publik.
3. Tambahkan DownloadJob, history, dan queue.
4. Tambahkan validation, monitoring, legal pages, lalu deployment test.
